# Security policy

## Report a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through GitHub: the **Security** tab of this repository, then
**Report a vulnerability**. Or email **security@crawl4ai.com**.

Tell us what you found, how to reproduce it, and what it affects. We answer within 3 business days
and tell you when it is fixed.

## Scope

This repository holds the client libraries only. A problem in the Crawl4AI Cloud service itself
(the API at `api.crawl4ai.com`, the website, the console) is in scope too: report it the same way.

## Supported versions

The latest release of each SDK gets security fixes.
